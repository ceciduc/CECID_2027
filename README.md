# CECID - Centro de Estudiantes de Ciencia de Datos

¡Bienvenidos al repositorio oficial del **Centro de Estudiantes de Ciencia de Datos (CECID)**! Este espacio digital ha sido creado bajo los principios de transparencia, democracia, probidad y responsabilidad, asegurando que todas las acciones, normativas, actas y manejo de recursos sean públicos y accesibles para toda la comunidad estudiantil.
